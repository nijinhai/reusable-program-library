# C：受限符号提案、取得新计算和后续复用

冻结后运行。无外部模型API；本轮使用明确声明的受限符号元语法，不宣称发明元语法或神经自生拓扑。运行时仍以第一轮字符串DSL为基底。提案空间额外允许反转、字符替换、字段重排与整数仿射算术，配合少量前后处理；这些计算原先不作为运行时操作提供。提案器只接收fit/check，不接收设计族或生成参数，枚举、拟合参数、输出可执行Python表达式。先按表达式操作数、源码长度、规范源码排序，每题最多1024个候选；首个fit/check全对者入库，query只在答案冻结后读取。

种子801–803。每种子12个旧DSL可解历史任务、8个新能力来源题（四种生成族各2）、52个后续任务。后续含直接复用、外层包装、后处理、变更参数四层各12题，以及4个元语法外排序任务。每题fit/check/query=4/4/12。模板与标签由作者构造；改变词汇和顺序，不称为独立真实任务分布。

来源题先用旧运行时搜索，失败才调用提案器。保留完整源码、拟合/核验成本和初始见证。在旧历史成功轨迹上执行新函数，记录能否匹配已有二步片段；没有旧match不拒绝新计算。入库后冻结，不在线修改条件（排除B）。

后续三臂：BASE旧运行时；REPROPOSE先旧运行时，失败后逐题重新提案且不持久化；LIBRARY在运行时中加入来源题取得的冻结函数，可以与原语组合，后续不再提案。每题运行时8192行操作调用，LIBRARY其中新增函数上限1024；最高5个运行时动作。提案器额外费用全部入账，不假定两种策略总成本相同。来源取得费用同时列入REPROPOSE和LIBRARY；BASE只付共同旧题求解费用。

源码为受信任元语法产生的纯字符串/整数表达式，不读取文件或网络。表达式中的Call、Subscript、BinOp各算一个操作，执行前按该固定权重逐行计费；基础DSL每原语每行一次。特征/参数生成的字符扫描和墙钟单列。表达式权重不是CPU等价成本。完整函数预算不足不执行、不返回半结果。
