# 实验说明

## 任务与策略

使用种子 801、802、803。每个种子包含 12 道历史任务、8 道新函数来源任务和 52 道后续任务。每题划分为 4 条拟合样例、4 条检查样例和 12 条查询。

提案器只接收拟合与检查样例。后续任务的返回程序确定后，再进行查询评估。24 道来源任务均取得通过验证的程序，每个种子按源码去重后得到 7 个函数。

- **BASE**：仅使用基础字符串操作搜索。
- **REPROPOSE**：先使用基础操作搜索，失败后根据当前题样例重新合成函数。
- **LIBRARY**：将来源阶段取得的函数加入搜索动作，与基础操作组合；后续任务期间保持函数库固定。

运行时搜索预算为每题 8,192 次行操作调用，函数库策略其中最多使用 1,024 次新增函数调用，程序长度最多 5 个动作。验证失败时回退基础搜索，其费用计入策略成本。

## 成功数与调用成本

严格成功指一题全部拟合、检查及查询输出都正确。

| 策略 | 严格成功 / 156 | 增量操作调用 |
| --- | ---: | ---: |
| BASE | 0 | 1,164,276 |
| REPROPOSE | 135 | 1,183,560 |
| LIBRARY | 108 | 789,615 |

调用账本包含策略规定的来源取得、历史回放、后续搜索、验证和回退费用；共同旧求解成本 288,244 次另列。基础操作按每行每原语计费，新表达式按语法树中的 Call、Subscript、BinOp 数量赋予操作权重。

## 核心观察：复用成本与任务覆盖的取舍

固定函数库相对逐题重新合成，增量调用减少 393,945 次，即 `(1,183,560 − 789,615) / 1,183,560 ≈ 33.3%`；成功任务数由 135 降至 108，净少 27 道。这个结果同时体现了复用的收益和适用范围：直接复用及部分后处理组合表现较好，参数或格式变化更适合重新拟合。

33.3% 使用上表的增量账本作为分母；若将两策略各自的共同旧求解成本 288,244 次也加回，调用分别为 1,471,804 和 1,077,859，差额比例约为 26.8%。操作调用按声明的权重计量，墙钟时间单独记录。成功数与调用量一起报告，用于分析质量和成本之间的取舍。

由此得到的工程问题是：如何根据当前任务决定复用已有函数、继续组合搜索，还是重新生成程序。

## 各类任务表现

| 后续任务类型 | BASE | REPROPOSE | LIBRARY |
| --- | ---: | ---: | ---: |
| 直接复用 | 0/36 | 36/36 | 36/36 |
| 外层包装 | 0/36 | 36/36 | 27/36 |
| 后处理组合 | 0/36 | 27/36 | 36/36 |
| 参数或格式变化 | 0/36 | 36/36 | 9/36 |
| 排序 | 0/12 | 0/12 | 0/12 |

函数库对直接复用及部分后处理组合有效。参数被固化在函数中时，遇到新的替换符、分隔符或算术系数，需要重新拟合。外层包装任务中的失败也暴露了搜索调度问题：存在正确的组合路径，但当前搜索在预算内没有找到。

提案空间支持反转、字符替换、字段重排和整数仿射变换，以及少量前后处理。排序任务用于观察当前表达空间之外的行为。三个种子共享任务模板，改变词汇与任务顺序。

## 后续改进方向

- 将函数中的常量提取为参数，处理格式和系数变化。
- 根据当前输入和计算需求选择候选，减少无效搜索展开。
- 加入“先合成、失败再搜索”的策略，比较保存函数与重新生成的成本。
- 在更多任务族上评估组合能力，并绘制成功率与总预算的关系。

## 实现与复现

`Learned` 编译内置元语法生成的 Python 表达式。调用方应将其用于这些内部候选；若接收用户提供的代码，需要另行设计隔离执行环境。

完整协议见[原始协议](original_protocol.md)，历史计费修复见[修复记录](accounting_repair.md)。公开版本的从头复现与逐题核对记录见[VALIDATION.md](../VALIDATION.md)。

## 相关研究

程序库学习的相关工作包括：

- [DreamCoder](https://arxiv.org/abs/2006.08381)：将程序求解、库学习和引导搜索结合。
- [Stitch](https://arxiv.org/abs/2211.16605)：从程序语料中提取共享抽象。
- [LILO](https://arxiv.org/abs/2310.19791)：结合语言模型合成、程序压缩与库文档生成。

本项目围绕一个小型字符串运行时，实现从示例取得函数及后续组合复用，并比较三种策略的任务表现与成本。实验对照范围为本文所列策略。
